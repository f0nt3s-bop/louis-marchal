# Louis Marchal · Nous rejoindre

Projet étudiant (L3 CCA, IAE) : page carrières de Louis Marchal, entreprise fictive issue d'un cas de marketing RH.

Réalisé avec React, Tailwind CSS et Framer Motion.

- `npm install` puis `npx vite` pour le voir en local
- Chaque push sur `main` met le site en ligne via GitHub Pages (Settings > Pages > Source : GitHub Actions)
